# Conceptos de páginas interiores (borrador)

Tres variantes gráficas para el estilo de las páginas interiores del sitio de coaching, en la línea del portal (foto + degradado oscuro, tipografía Archivo). Generadas como referencia visual, no están enlazadas desde el sitio real.

- `interior-a-celeste.html` — Celeste editorial: líneas rectas, tipografía audaz.
- `interior-b-rojizo.html` — Rojizo cálido: formas redondeadas, botones tipo píldora.
- `interior-c-dual.html` — Dual-tono: combina celeste + rojizo ("un mismo origen, dos caminos").

Cada `.html` referencia las fotos del sitio con rutas absolutas (`/home/user/KSC/assets/img/...`), pensadas para previsualizarse en este mismo entorno. Los `.png` son capturas ya renderizadas para verlas sin necesidad de abrir el HTML.

Si más adelante se decide usar alguno, hay que adaptar la estructura a las páginas reales (`coaching/*.html`) y las rutas de imagen relativas.
